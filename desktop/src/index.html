Inkdown Desktop

Open a folder to browse its Markdown files. Select text in the page to highlight, format, or attach a footnote note; everything is written back into the .md file.

Ctrl/Cmd+PQuick open by file name
Ctrl/Cmd+Shift+FSearch text in folder
Ctrl/Cmd+EToggle source editor
Ctrl/Cmd+SSave now (autosave is on)

TeX math, mermaid diagrams, [[wiki links]] and code highlighting all render offline.
